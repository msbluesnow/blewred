# blewred — Превентивный комплекс защиты прямых трансляций

> **Превентивная система комплаенса и ИИ-защиты стримов с нулевой задержкой**  
> *“Use protection B4 it happens...”*

Добро пожаловать в официальную техническую документацию **blewred** — опенсорсного комплекса защиты трансляций в реальном времени, созданного для стримеров на **Twitch**, **YouTube** и **Kick**.

> 💡 **Впервые используете blewred?** Ознакомьтесь с **[Кратким руководством для стримеров](/ru/quickstart_streamer)**, включающим 4 простых шага настройки (видеокарта Nvidia, браузерное расширение, модели ИИ, OBS Studio).

> [!IMPORTANT]
> **Статус проекта: Альфа-версия (v0.5.0-alpha)**
> Комплекс `blewred` находится в стадии активной альфа-разработки. Возможны временные шероховатости и баги, а расширение функционала и оптимизации активно планируются и разрабатываются.

blewred предотвращает блокировки каналов, перехватывая запрещенный визуальный контент (NSFW/наготу, запрещенные символы), текст на экране (OCR) и тайминги опасных фрагментов в видеоплеерах (синхронизация с HTML5-плеерами) **до того**, как кадр увидят зрители или серверы платформы, вызывая мгновенное размытие на GPU и глушение звука в OBS Studio.

## 1. Архитектура системы и базовый принцип

blewred функционирует на базе асинхронного, полностью расцепленного конвейера с минимальным потреблением ресурсов (< 70 МБ ОЗУ, < 1% CPU в режиме PlayerOnly, < 15 мс инференс на GPU).

## 2. Режимы работы в реальном времени

blewred поддерживает 4 режима работы, переключаемых на лету без перезапуска OBS Studio или фоновых служб:

| ID | Название | Анализ экрана | Видеоплеер (Расширение) | Нагрузка на CPU | Статус и назначение |
| :---: | :--- | :---: | :---: | :---: | :--- |
| **0** | **Гибридный (Hybrid)** *(По умолчанию)* | Активен (GPU/OCR) | Активен (Упреждающий) | 1–3% | Полный комплекс защиты. Рекомендуется для стандартных стримов. |
| **1** | **Только плеер (Player Only)** | Пауза (0 FPS) | Активен (Упреждающий) | < 1% | Идеален для стримов с просмотром видео и максимального FPS в играх. |
| **2** | **Только экран (Screen Only)** | Активен (GPU/OCR) | Отключен | 1–2% | Защита экрана и игр без использования браузерного расширения. |
| **3** | **Ожидание (Standby)** | Пауза (0 FPS) | Пауза | < 0.1% | Режим паузы. Все маски цензуры и мьют звука мгновенно сбрасываются. |

### Защита от гонок состояний и атомарные поколения (MODE_GENERATION)
Для предотвращения применения устаревших масок цензуры или отложенных таймеров после переключения режима каждому изменению присваивается уникальный номер поколения (`MODE_GENERATION`). Фоновые асинхронные задачи сверяют номер поколения перед отправкой любых команд в OBS Studio.

## 3. Компьютерное зрение и нейросетевой каскад

### Двухступенчатый каскад нейросетей
Вместо запуска тяжелого детектора на каждом кадре blewred использует асимметричный двухступенчатый каскад:

1. **Этап 1 — Falconsai ViT Screener (224×224)**:
   - Анализирует кадр за ~1.5–3.0 мс через DirectML / ONNX Runtime.
   - Отсекает более 95% безопасных рабочих и игровых сцен без задействования локализатора.
2. **Этап 2 — NudeNet 640m Localizer (640×640)**:
   - Активируется только при обнаружении риска на первом этапе или при активном захвате цели.
   - Вычисляет точные координаты для 18 анатомических зон с сохранением пропорций 16:9 (Letterboxing).

### Трекер Zero-Miss и гистерезис
- **Адаптивное расширение контуров (+18% Dilation)**: найденные рамки автоматически расширяются для предотвращения краевого выхода контуров.
- **Память Hold-Decay (30 кадров)**: обнаруженная маска удерживается в течение 30 кадров (~500 мс) с затуханием уверенности, что исключает мерцание и случайные пропуски.
- **Динамический разгон до 60 FPS**: при фиксации опасности темп сканирования переключается с 5 FPS (фоновый скан) на 60 FPS (интервал 12 мс) за один кадр.

## 4. Распознавание текста (OCR) и тайминги плеера

### Интеграция с Windows Media OCR
blewred использует системный движок Windows WinRT OCR (`windows::Media::Ocr::OcrEngine`):
- **Без дополнительных весов**: встроен в Windows 10/11, не требует скачивания тяжелых моделей.
- **100% офлайн**: работает локально на устройстве без отправки данных в облако.
- **Поддержка языков**: нативное распознавание русского и английского текста.

### Модуль таймингов плеера (Fuzzy Timecode Parsing)
Стример может вставить скриншот расписания таймингов прямо из буфера обмена (`Ctrl+V`):
- **Синтаксическая нормализация**: распознает нестандартные форматы времени (`12:30-14:15`, секунды больше 59, произвольные тире и разделители).
- **Устойчивость к перемотке**: при перемотке вперед или назад в плеере система динамически пересчитывает горизонт упреждения.
- **Предупреждающее окно**: отображает обратный отсчет до приближающегося инцидента с возможностью отмены или ручного включения защиты.

## 5. Интеграция с OBS Studio (`obs-blewred`)

### Zero-Copy аппаратное размытие на GPU
Нативный плагин (`obs-blewred.dll`) внедряется непосредственно в 64-битный процесс OBS Studio:
- **Перехват конвейера D3D11**: размытие выполняется HLSL пиксельным шейдером (`PSCensor`) прямо в видеопамяти до кодирования кадра.
- **Чистый экран стримера**: монитор стримера не перекрывается и не размывается; цензура накладывается исключительно на исходящий поток.
- **Передача по UDP Loopback**: координаты рамок передаются из ядра blewred в OBS через локальные датаграммы UDP (`127.0.0.1:51799`) быстрее 0.2 мс.

### Аварийная заставка Censor Shield
В сценах OBS автоматически создается источник заставки (`blewred_Censor_Shield`). При масштабном инциденте система за 1 мс активирует заставку на весь экран и глушит звук, предотвращая бан канала.

### Автоматическое управление звуком (OBS WebSocket v5)
blewred **не осуществляет перехват микрофона через WASAPI и не тратит ресурсы на акустическое распознавание речи**, исключая задержки и рассинхронизацию звука. Управление звуком реализовано через протокол OBS WebSocket v5:
- **Автопоиск источников**: автоматическое обнаружение каналов микрофона и рабочего стола в OBS.
- **Мгновенное глушение**: отправка команд `SetInputMute: true` при обнаружении визуальных нарушений или срабатывании аварийной заставки.
- **Бесшовное включение**: звук мгновенно возвращается после очищения кадра.

## 6. Спецификация протокола WebSocket

blewred предоставляет локальный асинхронный мост WebSocket на `ws://127.0.0.1:51789`.

### Входящие команды (Клиент -> Сервер)

| `type` | Параметры | Описание |
| :--- | :--- | :--- |
| `set_language` | `language: "ru" \| "en"` | Переключение и сохранение языка интерфейса; синхронизирует всех клиентов, включая Censor Shield в OBS. |
| `set_operation_mode` | `mode: number (0..3)` | Переключение режима работы. |
| `toggle_censor_shield` | `enabled: boolean` | Включение или отключение оверлея Censor Shield в сценах OBS. |
| `toggle_shield_donate` | `enabled: boolean` | Включение/выключение баннера поддержки разработки на Censor Shield. |
| `set_ocr_enabled` | `enabled: boolean` | Включение/выключение OCR-детекции. |
| `set_nsfw_threshold` | `threshold: number (0.0..1.0)` | Настройка порога чувствительности. |
| `add_scheduled_cues` | `cues: Cue[], append: boolean` | Добавление или замена таймингов. |
| `delete_scheduled_cue`| `id: string` | Удаление тайминга по ID. |
| `clear_scheduled_cues`| *(нет)* | Очистка всех таймингов. |
| `set_cues_config` | `pre_warning_seconds, auto_censor, append_mode` | Обновление настроек планировщика. |
| `recognize_screenshot_cues` | `image: string (base64)` | Распознавание таймингов со скриншота через Windows OCR. |
| `check_models_status` | *(нет)* | Проверка наличия и контрольных сумм ONNX-моделей. |
| `start_models_download`| *(нет)* | Запуск фонового скачивания недостающих моделей. |

### Исходящие события (Сервер -> Клиент)

| `type` | Параметры | Описание |
| :--- | :--- | :--- |
| `init_state` | `language, obs_connected, rules_text, models_status, ...` | Полное начальное состояние движка при подключении клиента. |
| `language_changed` | `language: "ru" \| "en"` | Бродкаст-уведомление об изменении языка интерфейса. |
| `telemetry` | `fps, gpu_info, obs_connected, ocr_enabled, ...` | Живые метрики производительности. |
| `shield_donate_changed` | `enabled: boolean` | Бродкаст-уведомление об изменении видимости блока поддержки на Censor Shield. |
| `scheduled_cues_updated` | `cues: Cue[]` | Уведомление об изменении списка таймингов. |
| `cues_state_result` | `cues, config, player_sync` | Ответ на запрос состояния планировщика. |
| `recognized_cues_result` | `cues, raw_text, count` | Результат распознавания скриншота. |
| `lookahead_ticket_created` | `ticket_id, reason, eta_sec, preview_base64` | Событие приближения опасного фрагмента. |
| `lookahead_ticket_resolved` | `ticket_id, action` | Событие завершения/отмены инцидента. |

## 7. Сборка и разработка

### Системные требования
- **ОС**: Windows 10 / 11 (64-бит)
- **Rust Toolchain**: 1.77+ с MSVC (`rustup default stable-x86_64-pc-windows-msvc`)
- **Инструменты сборки C/C++**: Visual Studio 2022 или Build Tools с Windows SDK
- **Node.js**: v18+ LTS
- **OBS Studio**: Версия 28+ (WebSocket v5 на порту 4455)

### Сборка проекта

```bash
# 1. Клонирование репозитория
git clone https://github.com/msbluesnow/blewred.git
cd blewred

# 2. Запуск тестов
cargo test --manifest-path src-tauri/Cargo.toml

# 3. Сборка релизной версии
cargo build --release --manifest-path src-tauri/Cargo.toml

# 4. Сборка нативного плагина OBS (опционально)
plugins\obs-blewred\build_plugin.bat
```

Скомпилированный файл будет доступен по пути:
`src-tauri/target/release/blewred.exe`

## 8. Настраиваемые горячие клавиши (Hotkeys)

`blewred` оснащен встроенной системой кастомизации горячих клавиш:
- **Паник-кнопка (Экстренное глушение)**: по умолчанию **F9** (мгновенный мьют микрофона и рабочего стола в OBS на 3 секунды + аварийный экран Censor Shield).
- **Форсированный темп анализа (Threat Mode)**: по умолчанию **F8** (переключение видеоанализа между фоновыми 5 FPS и опасными 60 FPS).
- **Свободное переназначение**: поддержка любых составных сочетаний (`Ctrl`, `Alt`, `Shift`, `Win` + клавиша), запись прямо с клавиатуры и настройка области действия (глобально в Windows / локально в приложении).

## 9. Стандарты оформления интерфейса

Интерфейс blewred строго следует спецификации **Bootstrap V3 Dark Edition**:
- Панели (`.panel`, `.panel-default`, темный фон `#1a1f29`, границы `#2d3748`).
- Кнопки (`.btn`, `.btn-default`, `.btn-primary`, `.btn-success`, `.btn-warning`, `.btn-danger`, `.btn-sm`, `.btn-xs`).
- Бейджи и метки (`.label`, `.badge`, `.label-default`, `.label-success`, `.label-warning`, `.label-danger`).
- **Строгое правило — ноль атрибутов `title`**: всплывающие подсказки браузера запрещены во всем проекте. Все подсказки и горячие клавиши выводятся прямо в тексте элементов.
